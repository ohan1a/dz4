Условие задачи

В умном коворкинге два сканера: по лицу (A) и по карте (B). Система открывает дверь, если ровно один из сканеров вернул четный код доступа (такие коды выдаются временным посетителям). Запишите условие открытия двери.

АЛГОРИТМ

1. Начало.
2. Ввод кодов доступа с клавиатуры: значение сканера a и сканера b.
3. Проверка логического условия: значение condition вычисляется через ИЛИ (^) между условиями чётности обоих сканеров: c = (a % 2 == 0) ^ (b % 2 == 0).
4. Вывод результата: печать строки с пояснением «(1 - да, 0 - нет):» и вывод самого значения переменной c (0 или 1)
